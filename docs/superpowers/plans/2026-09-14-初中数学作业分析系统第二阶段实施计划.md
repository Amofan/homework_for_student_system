# 初中数学作业分析系统第二阶段实施计划

> **执行要求：** 实施本计划时使用 `superpowers:executing-plans` 按任务顺序推进；每个任务遵循“失败测试—最小实现—针对性验证—全量回归—差异审查”的闭环。未经用户明确授权，不执行提交、推送、部署、持久化数据库迁移或真实模型调用。

**目标：** 在保留现有核心教学闭环的基础上，建立稳定的自动化验证基线，补齐真实集成证据、分层练习 Word 导出和论文离线评测，使项目达到可演示、可答辩、可量化评价的毕业设计交付状态。

**架构：** 继续采用 Vue 单页应用和 Spring Boot 模块化单体。规则评分、画像统计和分层选题保持确定性；大模型仍通过后端可替换适配器提供建议；教师确认是写入正式成绩和生成教学材料的唯一入口。新增能力按测试基础设施、外部边界、教学功能和论文实验四类分开实施。

**技术栈：** Java 21、Spring Boot 4.1.1、Spring Security、Spring JDBC、Flyway、MySQL 8.4、H2、Apache POI、Vue 3.5.42、TypeScript 6.0.3、Vite 8.3.0、Element Plus、ECharts、JUnit、MockMvc、WireMock、Testcontainers、Vitest、Playwright、Python 3 标准库。

## 全局约束

- 项目目录固定为 `E:\0_all_private_project\homework_for_student_system`；
- 所有 Markdown 文档使用中文，代码标识、协议字段和命令可保留英文；
- 产品只面向初中数学教师，不新增学生端、家长端、在线考试、OCR、RAG、向量数据库和多学科能力；
- 模型建议必须经教师确认，未确认结果不得进入画像、错因统计和分层练习；
- 模型密钥只保存在后端环境变量中，任何请求、响应、日志和测试快照都不得包含真实密钥；
- 模型输入不得包含学生姓名、学号、班级名称、登录令牌和其他身份信息；
- 正式持久化数据库仍为 MySQL 8.4，结构修改必须新增 Flyway 迁移，不改写已经存在的 V1 至 V5；
- 一次性 H2 和 Testcontainers 数据库可以用于自动化测试；持久化 MySQL、真实模型、部署和远程状态变更必须单独获得授权；
- 不新增微服务、消息队列、向量数据库或独立 Python 在线服务；
- 每个任务结束时运行针对性测试并检查改动范围，不自动执行 Git 提交。

**接口：**

- 输入 CSV 只使用匿名样本编号；
- 输出 JSON 包含评分误差、容差命中率、错因分类指标、教师修改率、平均耗时和样本数；
- 脚本只使用 Python 标准库，避免引入独立在线服务。

- [ ] **步骤 1：定义匿名数据格式**

`grading_cases.example.csv` 表头固定为：

```text
case_id,total_score,teacher_score,ai_score,teacher_error_type,ai_error_type,teacher_modified,teacher_seconds,ai_seconds,input_tokens,output_tokens
```

示例数据必须是虚构数据，不包含姓名、学号和真实学校。

- [ ] **步骤 2：先写指标单元测试**

覆盖以下确定性样本：

```python
def test_score_metrics():
    pairs = [(8, 8), (6, 7), (5, 3)]
    assert mean_absolute_error(pairs) == 1.0
    assert within_tolerance_rate(pairs, tolerance=1) == 2 / 3
```

同时覆盖零样本、未知错因标签、除零保护和混淆矩阵。

- [ ] **步骤 3：实现论文核心指标**

脚本输出：

- 平均绝对误差 `MAE`；
- 评分完全一致率；
- 误差不超过 1 分的命中率；
- 各错因标签的精确率、召回率和 F1；
- 宏平均 F1；
- 教师修改率；
- 教师平均用时、AI 平均用时和估算节省比例；
- 输入、输出令牌总量，仅在 CSV 提供数据时计算。

- [ ] **步骤 4：生成机器可读结果**

命令固定为：

```powershell
python evaluation/evaluate_grading.py `
  --grading evaluation/data/grading_cases.example.csv `
  --output evaluation/output/metrics.json
```

`evaluation/output/` 加入 `.gitignore`；论文引用数据时把最终匿名数据和结果另行归档，不把真实学生信息提交到仓库。

- [ ] **步骤 5：编写中文实验记录模板**

## 里程碑与停止条件

### 里程碑一：可信回归基线

完成任务一、二。后端全量测试、前端单元测试、类型检查和构建必须稳定通过。未达到此条件，不开始分层练习开发。

### 里程碑二：外部边界可验证

完成任务三、四。模型适配器使用本地模拟服务验证；MySQL 使用一次性容器验证。二者都不需要真实业务数据。

### 里程碑三：教学闭环增强

完成任务五、六。教师能基于已确认画像生成、确认并下载三级练习 Word 文档。

### 里程碑四：论文与答辩就绪

完成任务七、八。实验脚本、匿名样本格式、自动化验证和中文交付文档齐全。

## 明确不在本计划中的内容

- 拍照识别、手写公式 OCR；
- RAG、向量数据库、知识库问答；
- 学生端、家长端、消息推送；
- 自动替教师发布成绩或把 AI 建议直接写成正式成绩；
- 多学科扩展、微服务拆分、云端部署；
- 未经授权的真实模型调用、持久化数据库迁移、Git 提交或推送。
